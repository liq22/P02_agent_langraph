## Operational endpoint and uncertainty

Use all canonical first outcomes. `no_submission` contributes a false negative to its true class and does not become a fourth averaged class. Distinguish provider interruption, malformed response, unavailable action, budget exhaustion and other native terminal categories. No unattempted assignment is assigned a zero score. A logged request without a complete canonical result is indeterminate and blocks automatic resend/completion; it is not an inferred diagnostic failure.

Primary reports: the two prespecified diagnosis differences with nominal 97.5% paired, diagnosis-class-stratified bearing-bootstrap intervals. Within each true class, resample bearings retaining their windows and model repeats. The interpretation conditions on observed class composition; no exact small-sample or provider-randomness coverage is asserted. Report estimates and intervals without a new binary significance procedure. Smoke/pilot observed-only reporting uses bootstrap=0. Replay and additional contrasts remain secondary/exploratory.

Also report submission rate, the three-class confusion matrix with `no_submission` column, native failure composition and descriptive Macro-F1 conditional on accepted submissions. Conditional completion subsets are treatment-dependent and never replace the primary metric. Their absence from a small pilot is not filled with inferred values.

## Mechanism definitions and falsification

The fixed diagnosis raw scope allows one distinct legal array. Repeated references to that array cannot support a multi-observation loss claim. The plausible gate mechanisms are numerical-progress enforcement, suppressed premature submission and post-prediction analytical closure.

Record attempts at submission before a successful model prediction over all first attempts. Among attempts reaching a successful prediction, record subsequent non-submit analytical actions. Among attempts with prediction and accepted final submission, compare first prediction and final label. Resolve supporting numerical artifacts separately; alias/reference-ID changes alone do not show new evidence. Record submission-error recovery and whether it reopens analysis. Explicitly report each denominator, including the count not reaching prediction or submission. Current rule/native tests prove possible interfaces, not these empirical rates; real CSV extraction and review must use the canonical event source.

A global arm that never continues after prediction has not demonstrated useful continuation. Changed labels may improve or worsen correctness; neither a changed label nor additional references establishes a beneficial mechanism. State/transition strata are descriptive, not causal subgroups. A correct-versus-wrong pointer diagnostic is only needed for a subsequent correctness-specific claim; it is not added before observing the primary total effect.

## Costs and interruption

Use request-start/finish records only for timing and request accounting, not as duplicate requests or canonical task outcomes. Pair them by invocation and request number; usage belongs to the finish record and is unknown when absent. Record planned condition position, first/last request time, observed reported model/provider and interruptions. An explicit resume can separate members of a block in time; do not delete that block or call it simultaneous. Uninterrupted-only results are descriptive sensitivities. A request intent without a sent request is possible, and losing both local logs and bundles remains outside the recovery check.
