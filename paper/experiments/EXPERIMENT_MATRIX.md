## 2. Endpoints on the same first-attempt cohort

**Primary:** pooled three-class operational Macro-F1. A canonical non-submission contributes FN to its true class, not a fourth averaged class. An indeterminate assigned attempt remains unresolved: no fabricated score, automatic replacement or omission from a purported complete cohort.

**Grounded secondary:** retain an accepted class only when native task-matched prediction agreement and required-feature-reference completeness both equal numeric1; a resolved failure maps to `no_submission`. Missing or malformed support fields leave that mapping unresolved even if the operational label is available. No inference from prose, cohort averages or a retrospectively favorable prediction. The native selected-reference rule and primary acceptance/scoring remain unchanged; shared cohort mapping still needs acceptance.

**Computational support:** retain role-bound raw-to-prediction ancestry and the final submission's selected prediction. Report required-role coverage, valid paths and submitted support with explicit denominators. Extra references do not imply numerical dependence; the graph predicate is not a replacement scorer.

**Replay:** report assigned, resolved, submitted, support-valid, eligible, attempted, matched, mismatched, failed and unresolved counts. Give support rates per submitted diagnosis and per assignment, and replay agreement among attempted paths with its coverage. Undefined denominators are not zero. Execute supported ancestors afresh with the same raw identity/slice/channels/rate and fitted assets; remap references. Freeze relevant software, hardware, floating-point and numerical random-state conditions. Class equality is exact; numeric rtol=1e−9 and atol=1e−12. Do not substitute cached outputs; cached-start checks validate only their downstream segment. Offline cost is separate. Computational reproduction is not a hardware-independent guarantee, physical explanation or causal feature necessity.

**Cost and failure:** retain native calls, tokens, latency and interruptions. Report common G/Φ computation separately from active-feedback tokens, changed execution and end-to-end cost; 11−10 does not estimate total instrumentation overhead. Count repetitions using the same bound inputs, operator/model and parameters; a new reference name is not new evidence. Distinguish intended verification from unintended repetition and unchanged results from a changed expert or input. Missing provider usage is not zero. Track premature submission, repeated roles, recovery and continuation descriptively, not as mediation estimates.

## 4. Control properties and counterexamples

The existing `evidence_phase` and `evidence_menu` maps implement Section3.4 without changing the treatment definitions. W is current-task window availability, R is existential structural role coverage, P is supported native prediction availability, E is the latest nonterminal error. Native-success flag N for10⁺ does not inspect graph support. Error precedence is inherited; terminal episodes cannot reopen.

On the same ordinary post-prediction prefix with f(h)=Submit and W=R=P=N=1, 10⁺ and11 both offer Check plus submission. Their prompts still differ. This is local menu equality, not equal policies or trajectories. Without schema discovery, an otherwise complete native prediction can have P=N=1,R=0; both allow analysis/submission, but only10⁺ permits another prediction. The new native copied-trace test preserves numerical executions while removing schema discovery from the copy. It verifies a boundary, not real-world incidence. Report matching-regime and boundary frequencies over all assigned attempts, with explicitly named conditional denominators; never select the analysis cohort using these treatment-dependent states.

Failed calls generate no numerical entities; duplicate IDs cannot overwrite prior entities; input producers precede consumers. Missing or rewired role edges must invalidate support with node attributes fixed and change relevant online predicates. Repeating one feature cannot fill another role. A successful native prediction can retain support without a schema query. Conversely, R=1 does not certify the particular proposed arguments. Native validation remains responsible for that distinction.

Observed expert disagreement is disclosed, not resolved using private labels. The deterministic fixture's equal labels across arms establish wiring, not LLM equivalence. Lossless flattening changes presentation; edge corruption changes information. A numerical feature intervention tests model sensitivity only when valid under the contract; invalid-input rejection is not evidence of physical causality or feature importance.

## 5. Real-data and inference freeze

Reserve development bearings for headroom/feasibility. Do not select final episodes because they exhibit favorable disagreement, corruptions or recoverability. Preserve zero/low headroom. Rereads and new IDs are not independent observations. Include the final-submission resource reserve; unresolved token/latency feasibility remains unresolved.

Bind every named condition to the shared canonical first-attempt path before provider execution. Final public events must reconstruct the same online graph, including submission. Use identical fitted assets per matched assignment, independent sessions, complete balanced blocks, absolute request times and resumed gaps. Reuse10/11 observations for continuation contrasts only under exactly compatible source, data, model, budget and first-attempt definitions; otherwise run a new prespecified compatible block. A changed route/model identity starts a new study. Never relabel best-available-attempt outputs.

Before pilot outcome inspection, freeze the principal package contrast and the added explanatory comparisons. Before confirmatory execution, settle paired bearing-level resampling, repeats, precision target and the endpoint/contrast family including multiplicity. No automatic transfer of the older indexing allocation. Pilot variation and event frequency guide precision, not retention of favorable hypotheses. Do not infer equivalence from a nonsignificant pilot.
