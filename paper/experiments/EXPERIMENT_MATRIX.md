## Data, sampling and timing

Diagnosis uses the native label ontology and Macro-F1; replay uses the native assigned-window metric and missing-score rule. Record task-family count, assigned bearing count and stochastic repeats separately. Fit only on training/validation assets and reuse the shared fitted-reference implementation. Test targets remain evaluator-side. Smoke outcomes validate the path and must not be used to tune prompts, stage rules or masks against evaluation labels.

`indexing.yaml` currently plans two task families × four conditions at one seed/rotation under the shared smoke asset limit. These are eight configuration cells, not eight completed episodes or a paper-sized cohort. A development pilot requires an inspected assignment; confirmatory asset/repeat counts and the model endpoint remain unbound until the data host is available. Do not invent these counts from the plan.

The current queue randomizes condition order by seed/rotation and executes each condition over its cohort. It does **not** interleave all conditions within each asset/trial. No such scheduling change is claimed. Formal provider-time attribution requires finer blocking or an explicitly restricted temporal interpretation before launching the confirmatory queue. Keep independent policy instances, timestamps, failures and all attempt costs. Never share message histories across arms.

Paired uncertainty resamples physical assets with the same draws for all contrast terms and recomputes cohort AP/F1. Post-treatment transition strata are descriptive, not causal subgroups. The two primary contrasts are declared before outcome inspection; the existing marginal interval procedure is not claimed to give joint familywise coverage. Additional placebo labels or learned routers are not added merely to populate an ablation list.

## Concrete restriction to test

Theory07 proves an error-free single-acquisition invariant for event-free **non-replay** masked trajectories. After one successful read, no remaining non-recovery stage exposes another read. A tool error reopens acquisition through Recover; replay can advance to the next sample. This is a conditional source property, not evidence that another permitted read is useful or that the controller harms diagnosis. Test any proposed harm only on assignments where the existing observation scope permits decision-relevant additional evidence; do not change the data protocol to manufacture that claim.

The six base menus are distinct; the dynamic Monitor/Revise/Recover menu collides. Report the implemented menu classes without inferring that an LLM reliably decodes them. Theory07 contains the instruction/capability table and the distinction between task utility and interface cost.
