## Fixed instruction inventory and attribution

Every organization condition receives the same ordered six-stage guide from the unchanged base guidance strings, exactly once per stage. The annotation adds the current stage name only; it does not repeat that stage's instruction. Annotation-off uses the same static guide at every history. Tool filtering uses the existing Graph set, and all four cells use the same top-level historical-state sanitation. No K-content, knowledge-retrieval, state-map, model, numerical-expert, data-protocol or metric intervention is added.

For the fixed assignment I and the native cohort statistic Theta, write theta^B_uv = Theta(D^B_uv(I)). Estimate both simple annotation effects, both simple filtering effects, their equal-weight marginal effects, the joint effect and the difference-of-differences. The existing `research/conditions.py` defines eight within-profile contrasts. No contrast imports historical Generic, original factorial or K-treated records. Recompute AP/Macro-F1 on pooled matched records within identical asset-block resamples; do not average episode F1/AP or count neighboring windows as new equipment.

An original cue-package gain with no fixed-instruction gain is compatible with benefit from supplied advice rather than this annotation. A negative fixed-instruction effect is retained. The design does not isolate annotation correctness from line salience/token cost; masks also convey stage information. Do not call these direct effects pure topology, full removal of state knowledge or measured optimal-value regret. A placebo or alternative state map is justified only by an observed unresolved effect, not added pre-emptively.

## Baselines, numerical capability and transport

Use the existing reactive, Scripted, original Graph and named component policies first. StateFlow's refined-prompt and state-removal controls are prior art; Reflexion needs its actual permitted-feedback loop and all calls before it becomes a reproduced baseline. PHMForge already includes verification, distractor and data-discovery ablations. Paper-reported scores are not same-protocol reproduction.

Learned representations, fusion, routing and objective ablations are conditional on an actual numerical question. A training-free Graph has no optimization loss to ablate. Fit any numerical model/normalizer/threshold without test access and verify its retained predictions with the native scorer. Reuse the shared fitted-reference implementation already present in the selected Benchmark head; do not add a second serializer for this paper. Keep its source version and actual validation distinct from the earlier interface-only CI pass.

The existing optional transport sources are PTB-XL, UCI HAR, SMAP/MSL, SMD and SWaT. Preserve their target multiplicity, subject/asset identity and temporal semantics as specified in DATA_DOWNLOAD_SOP. Their acquisition and admission are not completed here, and they cannot replace missing matched PHM control results.
