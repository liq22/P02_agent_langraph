# PHMGraph: literature evidence and contribution boundary

Review date: 18 September 2026. This focused review supersedes the earlier pointer/menu literature map; it is not a systematic or exhaustive literature review. **Thirty original papers were inspected beyond their abstracts, at the method and evaluation sections identified below, and all thirty are cited in the active manuscript.** The PROV-DM standard and the abstract-only MAP-Graph lead are recorded separately and are not counted toward thirty. “Read” here does not mean that every appendix, dataset or implementation was independently reproduced. Findings below describe the authors' evaluated settings; the final column is the present study's comparison and inference.

Sources are publisher/proceedings full texts or author manuscripts. The Smith–Randall copy was uploaded by its author; the CWL HTML is an author's rendering of the published article. Publication metadata is distinguished from the version inspected. PDF page numbers are one-based. Where screenshot access failed (notably GoT and CodeReAct), the substantive method/results text was inspected; no numerical conclusion relies on an unread figure. Preprint publication status is not inferred.

## What changed the scientific position

AiiDA 1.0 already separates logical and data provenance, including their different cycle properties. LLMCompiler already waits for tool dependencies and can replan from intermediate results. StateFlow establishes state-conditioned execution. TimeSage-MT includes typed dependencies and a staged orchestrated agent, and PHMForge directly evaluates industrial tool orchestration. These works rule out making “two graphs”, “provenance controls actions”, or “structured agents trade flexibility for grounding” standalone innovations.

The narrower empirical question is whether **deterministic, sample-bound numerical readiness has incremental value beyond the same native input validator**, with numerical experts and procedural content fixed. The current implementation's role checks are a PHM-specific contract instantiation, not a proof that all diagnostic problems require a graph. Lossless relational/JSON records can carry the same information. The factorial measures active feedback on top of common evidence processing; it does not estimate total graph overhead relative to an uninstrumented baseline.

## Additional sources, excluded from the thirty-paper count

**PROV-DM — `moreau2013prov`.** [W3C Recommendation, 30 April 2013](https://www.w3.org/TR/2013/REC-prov-dm-20130430/). Entity/activity, use and generation definitions are inherited. This is a standard, not an experimental paper.

**MAP-Graph — `wang2026mapgraph`.** Correct title: *MAP-Graph: Provenance-Aware Shared Memory for Multi-Agent Workflows*, arXiv:2608.10509v1, 11 August 2026. The author abstract describes ancestry-aware shared memory and an action-risk gate. The arXiv full text could not be obtained in this environment; accessible mirrors exposed the author abstract only. This is enough to reject a broad first-provenance-gate claim, but not enough for algorithmic equivalence or absence-of-ablation claims. No reported performance number is imported. The earlier bibliography title is corrected, not silently retained.

## Challenges, mechanisms and falsification

| Challenge | What prior work already supplies | Targeted mechanism | Observable contrast and falsifier |
|---|---|---|---|
| Compatible evidence versus call progress | Typed workflow/provenance and numerical tool validation | Deterministic per-role, current-window readiness | Broken/missing role changes readiness and menu; no change under a required-edge corruption would refute the implemented dependence |
| Control value versus information/cost | Feedback planning, workflow states and dependency scheduling | Active frontier exposure/admission under common numerical capability | 11−10 with common graph/Φ processing; grouped versus lossless rows changes presentation only. More cost without useful delivery is an admissible result |
| Supported execution versus correct diagnosis | Functional task tests, reproducible numerical workflows and statistical comparison | Separate operational score, supported-delivery/path/replay rates and costs | Correct unsupported guess and wrong supported prediction distinguish endpoints; agreeing experts/zero feasible alternatives limits continuation claims |

The mathematical formulation defines the empirical object; it does not convert missing experimental outcomes into a contribution. Before the real pilot, establish waveform/fit/split identity, native first-attempt cohort handling and the frequency of useful numerical alternatives. Keep the six historical result slots associated with their original protocols.

## Review uptake and rejected repairs

Adopt domain-specific input-role motivation, explicit deterministic state, overhead accounting, proper baselines and replay isolation. Do not adopt the following stronger claims: graph storage is necessary; a missing feature is accepted by the current native classifier; online experts are fitted in the episode; the graph fixes nonstationary signal physics; cached intermediate outputs prove fresh end-to-end replay; a numerical trace exposes hidden LLM reasoning; or a successful software fixture proves PHM superiority.

The full factorial is prospective. Condition 00 is the common-catalog reactive arm; it is not unmodified Generic. Flat11 shares the graph and exact predicates, so it cannot isolate the value of having dependency information. Common graph/Φ processing must be timed separately from active feedback. Any stronger mechanism decomposition needs a separately named, validated intervention rather than reinterpretation of these cells.
