# Canvas Files

`research_overview.canvas` and `current_focus.canvas` are generated by:

```bash
python scripts/build_canvas_from_graph.py
```

`framework_workbench.canvas` is initialized once by the same script and then preserved as a manual workbench.

## Roles

- `research_overview.canvas`: global P0-P4 scheduler overview, parent/immediate child nodes, and canonical graph edges.
- `current_focus.canvas`: the current `next_node`, its README/status cards, dependency neighborhood, local skill or fallback skill, and current-phase siblings.
- `framework_workbench.canvas`: manual method sketches, skill ideas, relation proposals, and framework notes.

Canvas files are a front-end IDE and projection layer. They are not canonical truth for node status, graph edges, or execution logic.
