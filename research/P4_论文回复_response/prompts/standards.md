# P4 response and rebuttal standards

## Purpose

Use these checks when a P4 node maps reviews, drafts point-to-point responses, binds evidence, or packages resubmission materials.

## Standards

- Atomize reviewer concerns before drafting. Every response should map to an issue row.
- Use three gates before final text: coverage, provenance, and commitment.
- Coverage gate: every reviewer concern is answered, intentionally deferred, or marked as needing input.
- Provenance gate: every factual sentence maps to paper text, review text, user-confirmed result, user-confirmed derivation, or future-work boundary.
- Commitment gate: every promise is already done, explicitly approved, or framed as future work.
- Answer directly first, then evidence, then implication for the paper.
- Concede narrowly when the reviewer is right. Do not fabricate experiments, numbers, citations, or promises.

## Stop Or Narrow

- Stop if venue limits, review source, or response scope are missing.
- Narrow if a response needs new experiments that are not approved or not feasible before deadline.
- Flag high-risk wording that could create a new unsupported commitment.
