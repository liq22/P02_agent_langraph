# VSLLaVA Response Letter

This directory contains the initial LaTeX response-letter template for the VSLLaVA manuscript submitted to Advanced Engineering Informatics.

## Before Submission

Replace the following placeholders:

- `TODO-MANUSCRIPT-ID`
- `TODO-DECISION-TYPE`
- `TODO-EDITOR-NAME`
- All reviewer comment and response TODO blocks in `Reviewers/R1.tex`, `Reviewers/R2.tex`, and `Reviewers/R3.tex`

Keep the original reviewer comments verbatim in `revcomment` boxes and write direct point-by-point responses in the paired `revresponse` blocks.
