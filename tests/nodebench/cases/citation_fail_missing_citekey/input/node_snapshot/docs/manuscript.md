# Missing Citekey

## Problem

The problem is a paper node that contains claims and local evidence words but no citation key. It is structurally complete and describes why reviewers need a stable reference trail before the node can be handed downstream.

## Route

This fixture demonstrates that a local table reference can support an audit sentence, but it cannot replace a bibliographic citekey in a proposal node. Table 1 records the fixture condition, the expected blocker, and the next action.
