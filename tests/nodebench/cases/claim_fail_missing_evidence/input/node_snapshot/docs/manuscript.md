# Missing Strong Claim Evidence

## Problem

The problem is a proposal node whose citation registry is valid but whose strongest statement is unsupported in its own sentence. A reviewer needs the claim-evidence validator to stop this before the text can appear in a paper draft.

## Route

The baseline context is cited here so citation integrity can pass [@claimFixture]. The node then states a deliberately unsupported strong claim in the next sentence. This method will significantly outperform every prior workflow.

## Boundary

The boundary is explicit: a valid reference list is not enough when the decisive sentence lacks direct support. The next action is to attach a citation, table, experiment, or artifact to the strong claim itself.
