# LaTeX Build Failure

## Methods

The manuscript node defines a method section, a citation trail, and a build artifact. The content is intentionally valid so the TeX build validator is the only intended blocker.

## Evidence and Citation

This fixture demonstrates that a manuscript cannot claim build readiness when a present TeX file fails compilation [@latexFixture]. The citation is resolvable, and the prose includes enough structure for earlier validators to pass.

## Boundary

The Boundary is explicit: a broken TeX artifact must stop manuscript handoff. The next action is to repair the TeX source or remove the build artifact until it is ready.
