# Checksum Policy

## Required checksums

Compute SHA-256 checksums for:

- `metadata.xlsx`
- `RM_017_Ottawa19.h5`
- `RM_101_THU_GEARBOX.h5`

Optional but recommended for all extension H5 files.

## Output file

```text
checksums.sha256
```

## Rationale

Checksums let Codex, PHMGA, and the final paper evidence chain prove that the data package used for experiments is the same package recorded in the submission-ready bundle.
